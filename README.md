# BroadcastTestTool

Androidのブロードキャスト（Broadcast Intent）を受信し、その内容をリアルタイムで表示・保存するためのテストツールです。
業務アプリのデバッグや、特定のインテントが正しく発行されているかの確認に利用できます。

## 主な機能

- **動的なアクション登録**: 受信したいブロードキャストのAction名を、アプリ画面から自由に追加・削除できます。
- **リアルタイム表示**: 受信したブロードキャストの内容（タイムスタンプ、Action名、Extras情報）をリスト形式で即座に表示します。
- **バックグラウンド動作**: フォアグラウンドサービスを利用しているため、アプリが背面に回っても受信を継続します。
- **ファイル保存**: アプリ起動ごとに新しいテキストファイルを作成し、受信したすべてのログを保存します。
- **Android 8.0+ 対応**: Android 8.0 (API 26) から最新の Android 14 (API 34) まで動作します。

## 使い方

1. アプリを起動します。
2. 「Action名を入力」欄に、監視したいブロードキャストのAction名（例: `com.example.CUSTOM_ACTION`）を入力し、「追加」ボタンを押します。
3. 必要なアクションをすべて追加したら、「開始」ボタンを押します。
   - Android 13以降では通知の許可が求められます。フォアグラウンドサービス稼働のために許可してください。
4. ブロードキャストを受信すると、画面下の「受信履歴」に内容が表示されます。
5. 受信した内容は、以下のディレクトリにテキストファイルとして保存されます。
   - `/Android/data/com.example.broadcasttest/files/broadcast_logs/`
6. テストが終わったら「停止」ボタンを押して稼働を終了してください。

## 開発環境

- **言語**: Kotlin
- **最小SDK**: 26 (Android 8.0)
- **ターゲットSDK**: 34 (Android 14)
- **ビルドシステム**: Gradle (Version Catalog)

## ビルド方法

プロジェクトのルートディレクトリで以下のコマンドを実行することで、APKを作成できます。

```bash
./gradlew assembleDebug
```

作成されたAPKは `app/build/outputs/apk/debug/app-debug.apk` に出力されます。

## テスト

ViewModelのロジックなどのユニットテストを実行するには、以下のコマンドを使用します。

```bash
./gradlew testDebugUnitTest
```
